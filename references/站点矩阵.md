# 三站站点矩阵（实测版）

> 数据日期：2026-11-03 ｜ 每条结论都有实跑记录支撑，见 `三站检索SOP.md` 附录 A
> 结论分三档：**一手可得**（站点官方答案/解析原文）、**半可得**（部分字段公开）、**不可得**（登录/付费墙）

## 2. 选站决策

| 场景 | 用哪个站 | 理由 |
|---|---|---|
| 广东/广州新卷选题（中考真题、一模二模、期中月考） | 二一 | 广东覆盖唯一达标；免登录可抓 |
| 需要官方答案/解析做交叉核对 | 出卷网（登录态） | 唯一能拿到一手解析全文 + 分步解答 |
| 快速自检填空答案列表 | 菁优网（游客态） | 详情页游客即见【答案】栏，零成本 |
| 外省同型题/教材原题补充 | 三站都可，按覆盖挑 | — |
| 广东题的答案核对 | 目前**无站可用** | 如实标注「待人工核对」 |

## 3. 已知限制（实测得出，别再重试）

1. **内嵌浏览器（Trae）不可用于登录态抓取** — 标签页属上层 IDE 会话，代理会话报 `Browser operation belongs to an inactive execution round`（实测 6 次）；browser_use 子代理报「不支持浏览器子代理隔离」。一律用独立 Chrome。
2. **360 极速浏览器 cookie 读不出** — `WinError 32` 独占锁；esentutl 备份 `-1032 JET_errFileAccessDenied`；CreateFileW `err 32`。不要在 360 上花时间。
3. **沙箱内启动的 Chrome 会被回收**（9222 拒绝连接）→ 必须沙箱外 + `Invoke-WmiMethod -Class Win32_Process -Name Create`。
4. **PowerShell `-File` 读含中文路径的 .ps1 会按 GBK 解码** → 逻辑一律写 `.py` 文件执行；需要 PowerShell 时用环境变量或内联命令。
5. **内联 `python -c` 引号易碎** → 一律写 `.py` 文件。
6. **菁优网静态请求拿不到题链** — `/ques/search?keyword=` 293KB 全是导航链接；真实题链 `/shiti/<uuid>` 由 JS 加载 → 必须 CDP。
7. **菁优网 `/math3/ques/` 不是题目列表页** — 是导航页（221 链接、题链 0）。
8. **CDP `Runtime.evaluate` 顶层不接受 `return`** — 写 `return 1+1` 报 `SyntaxError: Illegal return statement` → 表达式要包 IIFE `(function(){ return … })()`（`cdp_client.js()` 已自动包装）。
9. **标签页可能整体无响应** — 渲染进程卡死后 `Runtime.evaluate` 会**永久超时**（socket 40s）而不是立刻报错。→ 用 `cdp_client.pick_tab()` 先探测再挑页；别在死页上反复重试。
10. **选标签页不能无条件回退到任意页** — 在 `example.com` 上跑登录态检测会得到假 FAIL。→ 站点探查用 `fallback_any=False` 限定目标域名，没有匹配就新开。
11. **验证页判定只看可见文本** — 出卷网与二一首页 JS 里含 `title:"安全验证"` 字样，扫原始 HTML 会误判。→ 先剥 `<script>`/`<style>` 再匹配。
12. **HTML 实体在写文件时会被解码** — `.py` 里写 `.replace('&', '&')` 是空操作 → 用 `from html import unescape`。
13. **单次网络超时不等于站点有滑块** — 预检探滑块时一次 `WinError 10060` 就判 FAIL 是假警报 → 3 连发中有效样本 ≥2 才下结论；样本不足时报"网络异常，先重试"。

## 4. 各站请求配方

### 出卷网
```
检索  https://www.chujuan.cn/question/search?xd=2&chid=6&content=<kw>&page=1
详情  https://www.chujuan.cn/question/detail/<qid>          （登录态下页面上下文 fetch）
答案图 https://webshot.chujuan.cn/...ex.png?sign=...        （带 sign，无 cookie 亦可下）
```
答案一手性判定：详情 HTML 内出现 `webshot…ex.png` → 一手（官方解析图）；否则未取得。

### 菁优网
```
检索  https://www.jyeoo.com/ques/search/?keyword=<kw>      （游客会跳登录页）
详情  https://www.jyeoo.com/shiti/<uuid>                    （游客可读题干/小问/考点/答案栏）
题图  https://img.jyeoo.net/quiz/images/...                  （免 Referer 可下）
```
答案一手性判定：【解答】非空 → 一手；只有【答案】栏 → 半可得。

### 二一组卷网
```
检索  https://zujuan.21cnjy.com/question/search?xd=2&chid=6&content=<kw>&page=N
      结果在页面内 window.SearchQuesResult = {...} JSON
详情  https://zujuan.21cnjy.com/question/detail/<qid>?district_id=19
      解析：related_questions:null,…question: 之后的花括号 JSON（深度匹配）
题图  https://tikupic.21cnjy.com/...                          （免 Referer 可下）
```
答案一手性判定：详情 JSON `access=true` 且 `answer_text` 非空 → 一手；`access=false` → 登录墙，标「非一手」。
