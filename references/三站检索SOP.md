### 0.3 已知限制（实测得出，别再重试）

1. **内嵌浏览器（Trae）不可用于登录态抓取**：标签页属上层 IDE 会话，代理会话报 `Browser operation belongs to an inactive execution round`（实测 6 次）；browser_use 子代理报「不支持浏览器子代理隔离」。→ 一律用独立 Chrome。
2. **360 极速浏览器 cookie 读不出**：`WinError 32` 独占锁；esentutl 备份语义 `-1032 JET_errFileAccessDenied`；CreateFileW `err 32`。→ 不要在 360 上花时间。
3. **沙箱内启动的 Chrome 会被回收**（端口 9222 拒绝连接）：必须 `dangerouslyDisableSandbox` + WMI `Invoke-WmiMethod Win32_Process Create` 启动，进程才脱离父 shell 生命周期。
4. **PowerShell 读 .ps1 文件时按 GBK 解码**：脚本内含中文路径（用户名/目录名）会乱码 → 一律把逻辑写进 `.py` 文件执行；需要用 PowerShell 时用**环境变量**或**内联命令**，不要用 `-File` 读含中文的脚本。
5. **`python -c` 内联引号易碎**：一律写 `.py` 文件执行。
6. **菁优网静态请求拿不到题链**：`/ques/search?keyword=` 293KB 全是导航链接（38 条），真实题链 `/shiti/<uuid>` 由 JS 加载 → 静态抓取失败，必须走 CDP。
7. **菁优网 `/math3/ques/` 不是题目列表页**：是导航页（221 链接、题链 0）。
8. **CDP `Runtime.evaluate` 顶层不接受 `return`**：写 `return 1+1` 报 `SyntaxError: Illegal return statement` → 表达式必须包一层 IIFE `(function(){ return … })()`。
9. **标签页可能整体无响应**：某个标签页的渲染进程卡死后，对它 `Runtime.evaluate` 会**永久超时**（socket timeout 40s），而不是立刻报错。→ 挑标签页时先探测（`cdp_client.pick_tab`），跳过无响应的；别在死页上反复重试。
10. **选标签页不能无条件回退到任意页**：在 `example.com` 上跑「登录态检测」会得到假 FAIL。→ 站点探查必须限定 url 含目标域名的标签页（`fallback_any=False`），没有就新开一个。
11. **验证页判定要看可见文本，不能扫原始 HTML**：出卷网与二一的首页 JS 里常含 `title:"安全验证"` 字样，直接正则扫 HTML 会把正常首页误判成验证页。→ 先剥掉 `<script>`/`<style>` 再匹配。
12. **HTML 实体在写文件时会被解码**：`.py` 里写 `.replace('&', '&')` 会变成空操作。→ 用 `from html import unescape` 处理实体。
13. **单次网络超时不等于站点有滑块**：预检探滑块时一次 `WinError 10060` 就判 FAIL 会造成假警报。→ 3 连发中有效样本 ≥2 才下结论，样本不足时报"网络异常，先重试预检"，不报"有验证"。

## 第一章 统一流程 P0–P9

每步格式：**输入 → 输出 → 判定标准 → 预算耗时**。预算超 2 倍立即停下报告（见 3.2）。

### P0 环境与账号预检（≤5 分钟，必跑）

| 子项 | 输入 | 输出 | 判定 | 预算 |
|---|---|---|---|---|
| P0.1 站点可达 | 三站 URL | HTTP 状态/耗时/字节 | 全部可达才继续 | 30s |
| P0.2 登录态（需要答案时才查） | profile 目录 | 登录标志（出卷网：页头手机号/充值中心） | 未登录→走 H1 交接协议 | 60s |
| P0.3 答案墙 | 一道详情页 | access / 答案容器是否存在 | 记录哪个站能给一手答案 | 60s |
| P0.4 滑块频率 | 连发 3 次检索 | 是否出现验证页 | 出现→走 H2 | 60s |
| P0.5 地区参数 | 带 district_id 的检索 | 结果是否全为广东 | 不生效→本地正则筛（既定结论） | 60s |
| P0.6 模型视觉 | Read 一张历史题图 | 能否描述图形 | 不能→**停止**，禁止自造 OCR | 30s |
| P0.7 目录可写 | 交付目录 + tmp | 写删探针 | 不可写→要白名单 | 20s |
| P0.8 查重基准 | items.ndjson | 行数>0 | 缺失→不能承诺查重 | 20s |
| P0.9 CLI 环境 | python -V + PIL/numpy | 版本与依赖 | 缺库→只用标准库 | 30s |

**硬规则：探测到客观限制立刻上报，禁止自研绕路。** 上报模板：现状 + 证据 + 需要用户做的一个动作 + 不做的影响。
反面教材：2026-11-02 晚 22:20–23:14 为找二一答案接口自研 `dbg1~15.py`/`probe_*.py`/`cdp_*.py`，55 分钟零产出。

### P1 知识点 → 检索关键词（≤2 分钟）

输入：训练点（如"杠杆"）+ 题型偏好（计算/实验/作图）+ 地区偏好（广东优先）。
输出：每训练点 3–5 组关键词 + 站点 + chid 映射。
判定：每组关键词至少能命中 1 道同型题，否则换词。
脚本模板：`tmp/search8.py`（二一）、`tmp/gdsearch2.py`（广东扩展）。

### P2 检索出候选（≤4 分钟）

输入：P1 关键词表。输出：候选池（含 qid/题型/难度/试卷名/题干摘要）。
判定：每训练点候选 ≥8 道；中等难度（diff=3）占比 ≥40%；广东题用 paper_title 正则筛。
实测参考：二一 14 组关键词 27s；出卷网 21 组×3 页 2min。

### P3 批量抓详情（≤3 分钟）

输入：候选 qid 列表。输出：详情 HTML/元数据 JSON + 题图。
出卷网/菁优：必须走 CDP（`tmp/cdp2.py` 页面上下文 fetch / 导航）。
二一：requests 直接抓（`tmp/zdetail.py`）。
判定：单题抓取失败 **≤2 次即弃用该候选**，不重试到成功（实测 68113229 弃用原则）。
题图：出卷网/二一 tikupic 无防盗链；菁优 img.jyeoo.net 实测免 Referer 可下。

### P4 题干与题图解析（≤8 分钟）

输入：详情 HTML + 题图。输出：结构化题干（含小问）、题图本地文件、图形要点。
判定：装置图/刻度图必须放大 4x 复核（用 `tmp/zoom.py` 固化的 crop+resize 流程，不手写）。
禁止：无原生视觉时不得用本地 OCR/像素分析（见 `选题流程_SOP.md` 第二章两条判据）。

### P5 查重（≤3 分钟）

输入：入库基准 items.ndjson（TM 编号 → 题干指纹）。输出：查重结论（全新/疑似/重复）。
判定：不同 qid 但同卷同题 → 判重；试卷名相同但题目不同 → 保留。

### P6 独立验算（≤8 分钟，与 P4 并行）

输入：题干 + 学生作答。输出：可独立复核的答案与过程。
判定：与平台答案冲突 → 以平台为准并记录冲突；平台答案不可得 → **标注"非一手，需人工核对"**，不得编造。

### P7 匹配与遴选（≤3 分钟，人工卡点）

输入：候选池 + 孩子薄弱点档案 + 验算结论。输出：最终选题清单 + 备选清单。
打分维度（各高/中/低 + 一句理由）：考点贴合度、难度、题型近本地卷、有无图形/装置、答案可独立验算、来源可查。
判定：不为换而换；外省题若更贴考点可留用但必须写明理由。

### P8 学生版/答案版产出（≤4 分钟）

输入：最终清单 + 题图目录。输出：学生版 HTML（**零答案零提示**）+ 答案版 HTML（含答案+验算过程+非一手警示）。
判定：学生版全文检索"答案/解析/答："必须 0 命中（交付前自检）。

### P9 入库与建任务（≤2 分钟）

输入：最终清单。输出：TM-0000XX 编号入 items.ndjson + 今晚任务清单。
判定：编号连续、题干指纹入库、清单文件带版本号（v2 等）。

**P9-b 飞书入库（≤5 分钟，必须做）**：items.ndjson 只是本地快照，飞书多维表格才是正式题库。

| 项 | 值 |
|---|---|
| 落点 | 云盘 `小兔中考 * 知识库` → 多维表格 **`2027广州中考·AI精准训练知识库`** |
| app_token | `AWswbQsLQajsaMsvVQmcSyz3nPc` |
| 题目库 table_id | `tblFlwLDZkzQX2Wq` |
| 训练任务库 table_id | `tblFEVEPllFOztXp` |
| 检索与选题记录 table_id | `tblS8boB3Zm90SHg`（**空表，选题必填**） |

**首选方式：`scripts/push_lark.py`**（幂等、自动续编号回查、record_id 真关联、题图自动上传）：

```bash
python scripts/push_lark.py --check                        # 连通性验证（可并入 P0）
python scripts/push_lark.py --manifest lark.json --dry-run # 预览，不落库
python scripts/push_lark.py --manifest lark.json --out push_result.json
```

manifest 格式见 `assets/lark_manifest_template.json`。写入顺序固定为 题目→任务→检索记录（检索记录要真关联任务 record_id）。题目ID/任务ID 是自动编号字段，由服务端分配，脚本写入后回查取得。

手工兜底（脚本不可用时）：`lark-cli base +record-upsert --base-token <app> --table-id <tid> --json '{字段map}'`；题图用 `lark-cli base +record-upload-attachment --record-id <rid> --field-id 题目图片 --file <png>`。注意 `--json` 是顶层字段 map 不套 `fields`；select 传 `["中"]`；链接传 `[{"id":"recXXX"}]`；`api` 命令的 `--page-all` 会混入进度行破坏 JSON，分页一律用 `--params '{"page_size":500,"page_token":...}'`。

写入三张表：
1. **题目库**：题干、题目ID（自动编号）、学科、年级、关联知识点（关联到知识点库 record_id）、题目名称、题目图片、题型、难度、题目来源、年份、来源链接、标准答案、解题解析、审核状态（`待审核`）、训练状态（`未用`）、去重键、审核意见与评估明细。
2. **检索与选题记录**（**每轮选题必填**，用于复盘检索质量）：检索批次ID、日期、训练目标、检索平台、原始提示词、提示词版本、筛选条件、结果数量、候选题链接与待核实资料、每题评估与淘汰原因、检索限制、关联训练任务、关联知识点、候选题、最终入选题。
3. **训练任务库**：任务ID（自动编号）、任务名称、训练日期、学科、关联知识点、关联题目、训练目标、计划题量、目标正确率、预计用时(分钟)、任务状态、优先级与选择理由、目标难度与达成标准、完成期限。

**入库判定**：
- 回查题目库，用「题目ID + 去重键」确认写入成功、条数正确（push_lark.py 自动完成并输出结果 JSON）。
- 关联知识点/关联题目必须真连上 record_id，不能只写文本。
- 答案栏若为「独立验算·非一手」，**审核状态保持 `待审核`**，并在「审核意见与评估明细」写明"非一手答案，需人工核对后再对答案"。
- 回查结果与本地 items.ndjson 一致（本地落后时以飞书为准并回导补齐）。
- 飞书凭据不可用时（`lark-cli` 报 validation/auth 错误）→ **明确报告"飞书未入库"**，不静默跳过。注意：`lark-cli auth status` 在凭据外部注入环境下不可用，连通性一律以 `push_lark.py --check`（即 `api GET records`）为准。

## 第二章 用户交接协议（关键）

**凡需要用户动手的步骤，必须完整走完 H 流程，禁止让用户操作后系统无声卡住，禁止同一问题反复让用户重做。**

### H 通用五步

1. **系统先备好窗口/页面**：把该点的页面打开到"只差用户点一下"的状态（已启动独立 Chrome、已停在登录页或验证页、已填好关键词）。
2. **明确告诉用户点什么**：给出**窗口标题 + 页面位置 + 具体动作**，一句话可执行。例："Chrome 窗口『出卷网 - 登录页』，点右上角手机号图标 → 输入你注册时用的手机号与验证码 → 回车"。
3. **用户完成后系统自动复验**：不靠"用户说好了"，由系统主动复验登录态/验证状态（出卷网=读页头是否显示手机号；滑块=检测验证页是否消失）。
4. **输出 PASS / FAIL 及原因**：PASS 才继续；FAIL 必须写清失败在哪、还差什么、下一步是什么。
5. **不重复打扰**：同一交接点失败两次即换方案（H3），第三次转为"报告失败并停止"，不纠缠用户。

### H1 登录交接（出卷网/菁优网）

- 触发：P0.2 检测到未登录，或详情页 302 到登录页。
- 步骤：
  1. 用 WMI 启动独立 Chrome（`tmp/launch_chrome.py` 模板，固定 profile `browser_profile`，端口 9222），**必须 `dangerouslyDisableSandbox`**。
  2. 导航到目标站登录页，等待渲染。
  3. 告诉用户：窗口标题（如「出卷网 - 登录页」）、点哪里、账号从哪来（用户自己输入，**系统不代填密码/验证码**）。
  4. 轮询复验：出卷网读页头 `1xx****xxxx` + 「充值中心」；菁优读标题是否已非「用户登录」+ 是否显示用户名。
  5. 输出 `登录态: PASS` 或 `登录态: FAIL（原因）`。
- 注意：登录态存于 `browser_profile`，重启 Chrome 不丢；**不要让用户在 Trae 内嵌浏览器里登录**（系统读不到，见 0.3-1）。

### H2 滑块/验证交接

- 触发：检索或详情返回验证页。
- 步骤：同 H1，页面停在验证页 → 告知用户"窗口『XXX』中间的滑块，拖到最右"→ 复验 → PASS/FAIL。
- 铁律：**不许自研绕路**（不写 JS 模拟、不破解、不换 IP 池）。一次失败即换 H3。

### H3 用户不便配合时的降级

1. 免登录可得的照常做（出卷网检索 JSON / 二一全流程 / 菁优游客详情页）。
2. 需要登录才能拿的部分 → 标注"该站答案非一手/未取得"，并在交付物中如实说明。
3. 任何情况下**不伪造登录态、不绕过付费墙**。

## 第三章 失败退出规则与预算

### 3.1 单步预算

| 步 | 预算 | 超限动作 |
|---|---|---|
| P0 | 5 min | 停下报告未通过项 |
| P1 | 2 min | 换关键词组 |
| P2 | 4 min | 换站/换词，明确告知用户该型题稀缺 |
| P3 | 3 min | 单题 2 次失败即弃用 |
| P4 | 8 min | 优先保题干，图形细节标注"未放大复核" |
| P5 | 3 min | — |
| P6 | 8 min | 标"待人工核对"继续下一题 |
| P7 | 3 min | — |
| P8 | 4 min | 先出可用的简版，再补全 |
| P9 | 2 min | — |
| **全流程** | 18 题 ≤30 min | 见 3.2 |

### 3.2 硬性退出规则

1. **任一环节超预算 2 倍 → 立即停下并报告**，写清：已做什么、卡在哪、需要什么决策。继续跑等于重演 31 分钟 OCR 绕路。
2. **同一问题重试上限 2 次**（第 3 次必换方案或放弃）。
3. **禁止自研绕路清单**（历史踩坑，全部禁止）：自造 OCR/像素识别；逆向答案接口；改 UA/IP 规避验证；解析付费墙；解密他人浏览器 cookie 数据库。
4. **静默失败禁止**：任何一步失败必须显式输出 FAIL+原因，不允许"卡住不吭声"。
5. **预检未跑不得开检索**：P0 未 PASS 的项若必需 → 走 H 协议，不许硬上。
